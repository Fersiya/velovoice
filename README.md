# VeloVoice 2.0 — свой лёгкий «Discord» на Rust + Tauri 2.0

Минималистичное десктоп-приложение для компании до 8 человек:
- **Встроенный сервер сигналинга прямо в `velovoice.exe`** — один человек нажимает *«Создать комнату»*, копирует код приглашения (`VV2:...`) и скидывает друзьям.
- **Автоопределение Tailscale / LAN IP** для быстрого подключения друзей без проброса портов.
- **Честный мониторинг ОЗУ** — прямо в окне видна суммарная память `velovoice.exe` + всех его процессов WebView2.
- **Полноценная настройка и проверка микрофона** — живая полоска громкости (RMS), порог речи, режим *«Слышать себя»*, выбор устройства вывода и горячая смена микрофона без разрыва связи.
- **Трансляция экрана до 1440p 60 FPS со звуком** + выбор битрейта и плавное отображение.
- **Встроенный текстовый чат** внутри комнаты.

## Сборка через GitHub Actions

При каждом `push` в `main` автоматически собираются:
- `velovoice.exe` — портативный десктоп-клиент (уже со встроенным хост-сервером);
- `VeloVoice_0.2.0_x64-setup.exe` — установщик Windows;
- `velovoice-server.exe` — отдельный сервер сигналинга (если захочешь вынести на VPS).

Готовые файлы появляются в разделе **Releases → VeloVoice 2.0 (Latest Build)**.
